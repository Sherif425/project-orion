# Study Workflow

## Purpose

Project Orion follows a structured learning workflow designed to transform theory into practical engineering experience.

---

# Weekly Workflow

Every topic follows the same sequence.

## Step 1 — Theory

Study the concepts and understand the engineering problem.

---

## Step 2 — Hands-on Lab

Practice the concepts in isolation.

Focus on understanding rather than speed.

---

## Step 3 — Mini Project

Apply the new knowledge to solve a focused engineering problem.

---

## Step 4 — Production Project

Expand the mini project into a professional solution when appropriate.

Projects should emphasize:

* Maintainability
* Documentation
* Code quality
* Reusability

---

## Step 5 — Documentation

Record:

* Objectives
* Implementation
* Challenges
* Lessons learned

Documentation is part of the engineering process.

---

## Step 6 — Git

Commit completed work using meaningful commit messages.

Push changes regularly.

---

## Step 7 — Review

Review:

* What was learned
* What can be improved
* What should be revisited later

Continuous improvement is an expected part of the learning process.

---

# Weekly Outcome

Each completed week should produce:

* New knowledge
* Hands-on practice
* One or more reusable projects
* Updated documentation
* GitHub commits
* A stronger engineering portfolio
