# Sprint 01 Retrospective

## Goal

Build a production-quality Python application using only the Python Standard Library.

---

## Completed

- Python Object Model
- Modules
- JSON
- pathlib
- Logging
- Exception Handling
- Inventory Collector

---

## Engineering Principles Learned

- Explicit is better than implicit.
- One module, one responsibility.
- Main orchestrates; modules implement.
- Handle expected failures explicitly.
- Initialize shared services once.
- Use the standard library before external dependencies.

---

## Challenges

- Understanding references
- Understanding function objects
- Understanding exception propagation
- Logging architecture

---

## Lessons Learned

The Python Object Model explains variables, functions, modules, and exceptions.

Understanding the architecture first makes advanced features much easier to learn.
