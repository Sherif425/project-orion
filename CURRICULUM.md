# Curriculum

## Purpose

The Orion curriculum provides a structured path for mastering Python through engineering practice.

The curriculum is organized into four complementary learning tracks that progress together throughout the project.

---

# Track A — Python Software Engineering

## Learning Outcomes

By completing this track, you will be able to:

* Write clean and maintainable Python code.
* Design modular applications.
* Apply object-oriented programming effectively.
* Use functional programming techniques where appropriate.
* Package and distribute Python applications.
* Test software using modern testing frameworks.

### Topics

* Python Fundamentals
* Functions
* Modules
* Packages
* OOP
* Functional Programming
* Design Patterns
* Exception Handling
* Logging
* Type Hints
* Testing
* Packaging

---

# Weekly Learning Structure

Each week follows the same workflow:

1. Study the theory.
2. Complete the hands-on lab.
3. Build a mini project.
4. Expand it into a production-quality project when appropriate.
5. Document the implementation.
6. Commit changes to Git.
7. Review lessons learned.

---

# Project Categories

Projects are grouped into five categories:

* Automation Tools
* Database Tools
* Data Analysis Applications
* Data Engineering Pipelines
* APIs and Dashboards

Each completed project should demonstrate practical engineering skills while contributing to a professional portfolio.

---

# Assessment

Progress is evaluated through completed work rather than examinations.

Success is measured by:

* Quality of code.
* Problem-solving ability.
* Project completeness.
* Documentation quality.
* Git history.
* Continuous improvement.

---

# Expected Outcome

Upon completing the curriculum, you will possess a portfolio of practical Python projects demonstrating competence in software engineering, infrastructure automation, database administration, data analysis, and data engineering.

The emphasis is not on the number of topics studied, but on the ability to design, implement, document, and maintain professional software solutions.
