# Project Orion Charter

## Vision
Build a professional engineering laboratory where Python is the primary language for solving real-world problems in automation, databases, DevOps, data engineering, and software development.

## Mission
Develop production-quality projects while documenting engineering decisions, lessons learned, and best practices.

## Scope
- Python projects
- Linux automation
- Database administration
- DevOps
- Data Engineering
- AI-assisted engineering

## Non-Goals
- Becoming a theory-only course.
- Collecting documentation without practical implementation.
- Covering every technology.

## Guiding Principles
1. Learn by building.
2. Document what matters.
3. Prefer simplicity.
4. Automate repetitive work.
5. Write maintainable code.
6. Keep a portfolio-ready standard.

## Success Metrics
- Complete planned sprints.
- Publish working projects.
- Maintain clear documentation.
- Build a portfolio demonstrating engineering skills.

## Definition of Done
A feature is complete when:
- Code works as intended.
- Documentation is updated.
- Tests (when applicable) pass.
- Code follows project standards.
- Changes are committed with meaningful Git history.
